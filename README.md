# termux-api-scripts

A specialized suite of hardware-interfacing scripts for Android, leveraging Termux:API for automated system telemetry and environment monitoring.

**Environment:** - OS: Android 10 and above
- Terminal: Termux v0.118+
- Dependencies: `termux-api`, `Termux:API` app

> Note: Termux and Termux:API should be downloaded from same source

## 📁 Available Tools
* [pwrlog](./pwrlog/) - Overnight drain telemetry.
