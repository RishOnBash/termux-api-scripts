## 🖼️setwall
Loop wallpaper for given period of time in seconds (default: 10 seconds).

### How to

- Set wallpaper directory.
- Run the script, `./setwall ~/storage/dcim/Wallpapers/ 15`, this rotates every wallpaper for 15 seconds.

> \[!NOTE]
> This changes wallpaper for both Home screen and Lock screen.
